# Запись демо NEBO

GIF в корневом README записан на [рабочем сайте](https://weather-app-sage-six-68.vercel.app/). Все показания в кадре получены от WeatherAPI в момент записи. Файлы лежат в `docs/demo/`, поэтому не попадают в сборку сайта.

1. Откройте NEBO на компьютере и дождитесь загрузки прогноза. Оставьте фон в режиме «Авто». Выберите город с ясной погодой, затем через меню города перейдите в город с осадками и откройте почасовой прогноз.
2. Снимите только область сайта, без интерфейса браузера. Оставьте первую секунду на главном экране, чтобы из неё можно было взять статичный кадр. В конце дайте время прочитать график.
3. Экспортируйте GIF и статичный кадр. Если исходник называется `recording.mp4`, запустите из корня репозитория две команды FFmpeg.

   ```sh
   ffmpeg -i recording.mp4 -filter_complex "fps=10,scale=800:-2:flags=lanczos,split[a][b];[a]palettegen[p];[b][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" -loop 0 docs/demo/nebo-demo.gif
   ffmpeg -ss 0.5 -i recording.mp4 -frames:v 1 -vf "scale=800:-2:flags=lanczos" -q:v 3 -update 1 docs/demo/nebo-demo-cover.jpg
   ```

4. Декодируйте GIF целиком. FFmpeg покажет длительность, разрешение и число прочитанных кадров, а при ошибке завершится с ненулевым кодом.

   ```sh
   ffmpeg -hide_banner -xerror -i docs/demo/nebo-demo.gif -f null -
   ```

5. Проверьте, что график читается и переходы видны. Ориентир для размера файла — до 4 МБ. Если сценарий изменился, обновите отметки времени, длительность и альтернативный текст в [корневом README](../../README.md#демо).
6. После публикации откройте README на GitHub. Проверьте обычный просмотр и просмотр с системной настройкой уменьшения движения, при которой должен загружаться статичный кадр.
